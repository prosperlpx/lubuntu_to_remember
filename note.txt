using grep
grep is a powerful program used to find text patterns within files. It is used like  this:
grep pattern [file...]: the pattern can be in quotes or not

You can also search multiple files at once. For example, if we wanted to search for the word "hello" in hello.txt and hello2.txt, we could run:
e.g: grep "hello" hello.txt hello2.txt

grep "script" . -r >> ~/serch_output.txt 2> /dev/null
what this code does up there is that it searches for the pattern "script" in the directory that is for every file it searches for the pattern in it and then returns the output.
